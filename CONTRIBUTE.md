# Contributing to Khaata Register app

Thank you for considering contributing to the Khaata App!  
We welcome developers of all skill levels.


## 📌 Project Setup

### 1. Clone the repository
```bash
git clone https://github.com/yasir13001/khaata-Register.git
cd khaata-Register
````

### 2. Setup Backend (FastAPI)

Create a virtual environment:

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the server:

```bash
uvicorn server:app --reload
```


## 📌 Code Style Guidelines

* Use meaningful function and variable names.
* Maintain consistent formatting (PEP8 for Python).
* Add comments where needed.
* Keep functions small and modular.


## 📌 Branching Strategy

* Create a **feature branch** for each change:

```bash
git checkout -b feature/your-feature-name
```

* Do not push directly to `main`.


## 📌 Submitting Contributions

### 1. Commit Messages

Use clear commit messages:

```
feat: add invoice QR code generator
fix: resolve autocomplete arrow navigation
docs: update README with screenshots
```

### 2. Pull Requests

* One feature or fix per PR
* Include screenshots for UI changes
* Reference related Issues
* Ensure code is tested


## 📌 Good First Issues (Recommended Areas)

* Improve invoice PDF formatting
* Fix date formatting (DD:MM:YY across project)
* Add dark mode
* Improve customer autocomplete (arrow key navigation)
* Add unit tests
* Add pagination to transaction tables
* Optimize SQL queries
* Add success/error notifications


## 📌 Community Rules
